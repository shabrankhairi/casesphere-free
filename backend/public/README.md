# CaseSphere Logo Pack

Included:
- `casesphere-logo-stacked.svg` — primary stacked logo
- `casesphere-logo-horizontal.svg` — horizontal header/navbar logo
- `casesphere-icon.svg` — icon-only mark
- `casesphere-logo-white.svg` and `casesphere-icon-white.svg` — for dark backgrounds
- PNG sizes for web and social media
- `favicon.ico`
- `apple-touch-icon.png`
- WebP version

Brand colors:
- Navy: `#001A3D`
- Blue: `#1267D9`

Recommended web use:

```html
<img src="/assets/casesphere-logo-horizontal.svg"
     alt="CaseSphere"
     width="260"
     height="83">
```

For favicon:

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/assets/casesphere-icon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

Notes:
- SVG files have transparent backgrounds.
- The wordmark uses a modern sans-serif fallback stack. For maximum visual consistency, use Montserrat on the website.
